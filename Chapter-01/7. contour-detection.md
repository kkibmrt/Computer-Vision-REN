# Apa Itu Contour Detection?

Contour Detection adalah teknik Computer Vision untuk mendeteksi bentuk, batas, atau tepi luar suatu objek pada gambar maupun video.

Contour merupakan kumpulan titik yang membentuk garis luar objek.

Pada Computer Vision, contour digunakan untuk:
- mendeteksi bentuk objek
- menghitung luas objek
- tracking objek
- mengenali pola
- robot navigation

---

# Fungsi Contour Detection

Beberapa fungsi utama contour detection:

| Fungsi | Penjelasan |
|---|---|
| Shape Detection | Mendeteksi bentuk objek |

# Bounding Rectangle

Bounding rectangle digunakan untuk menandai objek.

```python
import cv2


image = cv2.imread('image.jpg')


gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)


_, threshold = cv2.threshold(
    gray,
    127,
    255,
    cv2.THRESH_BINARY
)


contours, hierarchy = cv2.findContours(
    threshold,
    cv2.RETR_TREE,
    cv2.CHAIN_APPROX_SIMPLE
)


for contour in contours:

    x, y, w, h = cv2.boundingRect(contour)

    cv2.rectangle(
        image,
        (x,y),
        (x+w, y+h),
        (0,255,0),
        2
    )


cv2.imshow('Bounding Box', image)

cv2.waitKey(0)

cv2.destroyAllWindows()
```

# Minimum Enclosing Circle

Circle digunakan untuk membungkus objek.

```python
import cv2


image = cv2.imread('image.jpg')


gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)


_, threshold = cv2.threshold(
    gray,
    127,
    255,
    cv2.THRESH_BINARY
)


contours, hierarchy = cv2.findContours(
    threshold,
    cv2.RETR_TREE,
    cv2.CHAIN_APPROX_SIMPLE
)


for contour in contours:

    (x,y), radius = cv2.minEnclosingCircle(contour)

    center = (int(x), int(y))

    radius = int(radius)

    cv2.circle(
        image,
        center,
        radius,
        (255,0,0),
        2
    )


cv2.imshow('Circle Detection', image)

cv2.waitKey(0)

cv2.destroyAllWindows()
```

# Shape Detection

Contour dapat digunakan untuk mendeteksi bentuk objek.

```python
import cv2


image = cv2.imread('shape.jpg')


gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)


_, threshold = cv2.threshold(
    gray,
    127,
    255,
    cv2.THRESH_BINARY
)


contours, hierarchy = cv2.findContours(
    threshold,
    cv2.RETR_TREE,
    cv2.CHAIN_APPROX_SIMPLE
)


for contour in contours:

    approximation = cv2.approxPolyDP(
        contour,
        0.01 * cv2.arcLength(contour, True),
        True
    )

    sides = len(approximation)

    print("Number of sides:", sides)
```

---

# Penjelasan Shape Detection

Jumlah sisi:
- 3 → segitiga
- 4 → persegi
- 5 → pentagon
- banyak sisi → lingkaran

# Contour Detection Realtime

```python
import cv2


camera = cv2.VideoCapture(0)


while True:

    success, frame = camera.read()

    if not success:
        break


    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)

    _, threshold = cv2.threshold(
        gray,
        127,
        255,
        cv2.THRESH_BINARY
    )


    contours, hierarchy = cv2.findContours(
        threshold,
        cv2.RETR_TREE,
        cv2.CHAIN_APPROX_SIMPLE
    )


    cv2.drawContours(
        frame,
        contours,
        -1,
        (0,255,0),
        2
    )


    cv2.imshow('Realtime Contour', frame)


    if cv2.waitKey(1) == ord('q'):
        break


camera.release()

cv2.destroyAllWindows()
```

# Penjelasan Program Realtime

Program:
- membaca kamera realtime
- melakukan threshold
- mendeteksi contour
- menampilkan contour secara realtime
