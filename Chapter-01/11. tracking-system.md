# Apa Itu Object Tracking?

Object Tracking adalah teknik Computer Vision yang digunakan untuk:
- melacak pergerakan objek
- mengikuti posisi objek
- mempertahankan identitas objek pada video realtime

Tracking digunakan setelah object detection berhasil menemukan objek.

---

# Perbedaan Detection dan Tracking

| Teknologi | Fungsi |
|---|---|
| Object Detection | Mendeteksi objek |
| Object Tracking | Mengikuti pergerakan objek |

# Program Object Tracking Lengkap

```python
import cv2


camera = cv2.VideoCapture(0)


tracker = cv2.TrackerCSRT_create()


success, frame = camera.read()


bbox = cv2.selectROI(
    "Tracking",
    frame,
    False
)


tracker.init(frame, bbox)


while True:

    success, frame = camera.read()

    if not success:
        break


    success, bbox = tracker.update(frame)


    if success:

        x, y, w, h = [int(v) for v in bbox]


        cv2.rectangle(
            frame,
            (x,y),
            (x+w,y+h),
            (0,255,0),
            2
        )


        cv2.putText(
            frame,
            "Tracking",
            (x,y-10),
            cv2.FONT_HERSHEY_SIMPLEX,
            0.7,
            (0,255,0),
            2
        )

    else:

        cv2.putText(
            frame,
            "Tracking Failure",
            (50,80),
            cv2.FONT_HERSHEY_SIMPLEX,
            0.7,
            (0,0,255),
            2
        )


    cv2.imshow(
        "Object Tracking",
        frame
    )


    if cv2.waitKey(1) == ord('q'):
        break


camera.release()

cv2.destroyAllWindows()
```

# Penjelasan Program

Program:
- membuka kamera

- memulai tracker
- mengikuti posisi objek realtime
- menampilkan bounding box

# Program Multi Object Tracking

```python
import cv2


camera = cv2.VideoCapture(0)


multiTracker = cv2.MultiTracker_create()


success, frame = camera.read()


bbox1 = cv2.selectROI(
    'Multi Tracking',
    frame
)

bbox2 = cv2.selectROI(
    'Multi Tracking',
    frame
)


tracker1 = cv2.TrackerCSRT_create()

tracker2 = cv2.TrackerCSRT_create()


multiTracker.add(
    tracker1,
    frame,
    bbox1
)

multiTracker.add(
    tracker2,
    frame,
    bbox2
)


while True:

    success, frame = camera.read()

    if not success:
        break


    success, boxes = multiTracker.update(frame)


    for box in boxes:

        x, y, w, h = [int(v) for v in box]


        cv2.rectangle(
            frame,
            (x,y),
            (x+w,y+h),
            (0,255,0),
            2
        )


    cv2.imshow(
        'Multi Tracking',
        frame
    )


    if cv2.waitKey(1) == ord('q'):
        break


camera.release()

cv2.destroyAllWindows()
```
