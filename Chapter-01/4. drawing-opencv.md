# Drawing dan Shape pada OpenCV
## Menggambar Objek pada Gambar Menggunakan OpenCV dan Python

---

# 📌 Apa Itu Drawing pada OpenCV?

Drawing pada OpenCV adalah proses menggambar objek visual secara langsung pada gambar maupun video realtime menggunakan fungsi bawaan OpenCV.

Fitur drawing digunakan untuk:
- membuat visualisasi object detection
- menandai objek
- membuat bounding box
- menampilkan koordinat
- membuat GUI vision sederhana

---

# 🎯 Fungsi Drawing pada Computer Vision

Drawing sangat penting dalam sistem Computer Vision karena digunakan untuk:

| Fungsi | Penjelasan |
|---|---|
| Bounding Box | Menandai objek terdeteksi |
| Visualisasi AI | Menampilkan hasil deteksi |
| Tracking Object | Menampilkan jalur tracking |
| Robot Vision | Penanda target robot |
| Interface Vision | Membuat tampilan visual |

---

# 🧠 Workflow Drawing pada OpenCV

```text
Input Image / Camera
          ↓
Object Detection
          ↓
Coordinate Processing
          ↓
Drawing Shape
          ↓
Display Result
```

# 📌 Coordinate pada OpenCV

Pada OpenCV, posisi gambar menggunakan sistem koordinat:

```text
(x, y)
```

Dimana:
- x → horizontal
- y → vertical

---

# 📊 Posisi Coordinate

```text
(0,0) berada di kiri atas gambar
```

# 📏 Menggambar Garis

Fungsi line digunakan untuk menggambar garis.

| Parameter | Fungsi |
|---|---|

# Format Warna pada OpenCV

OpenCV menggunakan format warna:

```text
BGR
```

Contoh warna:

| Warna | Nilai BGR |
|---|---|
| Merah | (0,0,255) |
| Hijau | (0,255,0) |
| Biru | (255,0,0) |
| Putih | (255,255,255) |
| Hitam | (0,0,0) |

# Drawing pada Kamera Realtime

Drawing juga dapat digunakan pada video realtime.

```python
import cv2


camera = cv2.VideoCapture(0)


while True:

    success, frame = camera.read()

    if not success:
        break


    cv2.rectangle(frame, (100,100), (300,300), (0,255,0), 3)

    cv2.putText(
        frame,
        'Realtime Vision',
        (120,90),
        cv2.FONT_HERSHEY_SIMPLEX,
        1,
        (0,255,0),
        2
    )


    cv2.imshow('Realtime Camera', frame)


    if cv2.waitKey(1) == ord('q'):
        break


camera.release()

cv2.destroyAllWindows()
```
