# Apa Itu Image Segmentation?

Image Segmentation adalah teknik Computer Vision yang digunakan untuk:
- memisahkan objek dari background
- membagi gambar menjadi beberapa area
- mengenali bagian tertentu pada gambar

Segmentation membuat komputer mampu memahami area objek secara detail.

---

# Perbedaan Detection dan Segmentation

| Teknologi | Fungsi |
|---|---|
| Object Detection | Memberi bounding box |
| Image Segmentation | Memisahkan bentuk objek |

---

# Fungsi Image Segmentation

Segmentation digunakan pada berbagai bidang:

| Bidang | Contoh Penggunaan |

# Threshold Segmentation

Threshold digunakan untuk memisahkan objek dari background.

```python
import cv2


image = cv2.imread('image.jpg')


gray = cv2.cvtColor(
    image,
    cv2.COLOR_BGR2GRAY
)


_, threshold = cv2.threshold(
    gray,
    127,
    255,
    cv2.THRESH_BINARY
)


cv2.imshow(
    'Threshold',
    threshold
)

cv2.waitKey(0)

cv2.destroyAllWindows()
```

---

# Penjelasan Threshold

```python
cv2.threshold()
```

digunakan untuk:
- membuat gambar biner
- memisahkan foreground dan background

---

# Parameter Threshold

| Parameter | Fungsi |
|---|---|
| gray | Input grayscale |
| 127 | Nilai threshold |
| 255 | Nilai maksimum |
| THRESH_BINARY | Jenis threshold |

---

# Adaptive Threshold

Adaptive threshold lebih stabil pada cahaya berbeda.

```python
import cv2


image = cv2.imread('image.jpg')


gray = cv2.cvtColor(
    image,
    cv2.COLOR_BGR2GRAY
)


adaptive = cv2.adaptiveThreshold(
    gray,
    255,
    cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
    cv2.THRESH_BINARY,
    11,
    2
)


cv2.imshow(
    'Adaptive Threshold',
    adaptive
)

cv2.waitKey(0)

cv2.destroyAllWindows()
```

---

# Penjelasan Adaptive Threshold

Adaptive threshold:
- menghitung threshold otomatis
- cocok untuk pencahayaan tidak merata

# Segmentasi Warna

```python
import cv2
import numpy as np


image = cv2.imread('image.jpg')


hsv = cv2.cvtColor(
    image,
    cv2.COLOR_BGR2HSV
)


lower_blue = np.array([100,150,0])

upper_blue = np.array([140,255,255])


mask = cv2.inRange(
    hsv,
    lower_blue,
    upper_blue
)


result = cv2.bitwise_and(
    image,
    image,
    mask=mask
)


cv2.imshow('Mask', mask)

cv2.imshow('Result', result)

cv2.waitKey(0)

cv2.destroyAllWindows()
```

---

# Penjelasan Color Segmentation

Program:
- mengubah gambar ke HSV
- mencari warna biru
- memisahkan objek biru

# Morphological Operation

Morphological operation digunakan untuk:
- menghilangkan noise
- memperbaiki hasil segmentasi

---

# Erosion

```python
kernel = np.ones((5,5), np.uint8)

erosion = cv2.erode(

)
```

---

# Penjelasan Erosion

Erosion digunakan untuk:
- mengurangi noise putih
- mengecilkan objek

---

# Dilation

```python
dilation = cv2.dilate(
    threshold,
    kernel,
    iterations=1
)
```

---

# Penjelasan Dilation

Dilation digunakan untuk:
- memperbesar objek
- mempertegas area objek

---

# Opening Operation

```python
opening = cv2.morphologyEx(
    threshold,
    cv2.MORPH_OPEN,
    kernel
)
```

---

# Penjelasan Opening

Opening:
- erosion lalu dilation
- menghilangkan noise kecil

---

# Closing Operation

```python
closing = cv2.morphologyEx(
    threshold,
    cv2.MORPH_CLOSE,
    kernel
)
```

---

# Penjelasan Closing

Closing:
- dilation lalu erosion
- menutup lubang kecil objek

# Contour Segmentation

Contour juga dapat digunakan untuk segmentasi.

```python
import cv2


image = cv2.imread('image.jpg')


gray = cv2.cvtColor(
    image,
    cv2.COLOR_BGR2GRAY
)


_, threshold = cv2.threshold(
    gray,
    127,
    255,
    cv2.THRESH_BINARY
)


contours, hierarchy = cv2.findContours(
    threshold,
    cv2.RETR_TREE,
    cv2.CHAIN_APPROX_SIMPLE
)


cv2.drawContours(
    image,
    contours,
    -1,
    (0,255,0),
    2
)


cv2.imshow(
    'Contour Segmentation',
    image
)

cv2.waitKey(0)

cv2.destroyAllWindows()
```

---

# Penjelasan Contour Segmentation

Program:
- memisahkan objek
- mendeteksi area objek
- menampilkan batas objek
