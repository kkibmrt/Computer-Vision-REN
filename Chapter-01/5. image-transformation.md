# 📌 Apa Itu Image Transformation?

Image Transformation adalah proses mengubah bentuk, ukuran, posisi, maupun orientasi gambar menggunakan operasi matematika pada pixel gambar.

Pada Computer Vision, image transformation digunakan untuk:
- preprocessing AI
- normalisasi gambar
- augmentasi dataset
- menyesuaikan input model
- memperbaiki perspektif gambar

---

# Fungsi Image Transformation

Beberapa fungsi utama image transformation:

| Fungsi | Penjelasan |
|---|---|
| Resize | Mengubah ukuran gambar |
| Rotation | Memutar gambar |
| Translation | Menggeser gambar |
| Cropping | Mengambil bagian gambar |
| Flipping | Membalik gambar |
| Scaling | Memperbesar atau memperkecil |
| Warping | Mengubah perspektif |

---

# Resize Gambar

Resize digunakan untuk mengubah ukuran gambar.

# Resize Menggunakan Scale

Resize juga dapat menggunakan skala.

```python

    fy=0.5

```

| Parameter | Fungsi |

# Rotasi Gambar

Rotation digunakan untuk memutar gambar.

```python
import cv2


image = cv2.imread('image.jpg')


height, width = image.shape[:2]


center = (width//2, height//2)


rotationMatrix = cv2.getRotationMatrix2D(center, 45, 1)


rotate = cv2.warpAffine(
    image,
    rotationMatrix,
    (width,height)
)


cv2.imshow('Rotated Image', rotate)

cv2.waitKey(0)

cv2.destroyAllWindows()
```

---

# Penjelasan Rotation

## `getRotationMatrix2D()`

Digunakan untuk membuat matrix rotasi.

Parameter:

| Parameter | Fungsi |
|---|---|
| center | Titik pusat rotasi |
| 45 | Sudut rotasi |
| 1 | Scale |

# ↔ Translation Gambar

Translation digunakan untuk menggeser posisi gambar.

```python
import cv2
import numpy as np


image = cv2.imread('image.jpg')


matrix = np.float32([
    [1,0,100],
    [0,1,50]
])


translate = cv2.warpAffine(
    image,
    matrix,
    (image.shape[1], image.shape[0])
)


cv2.imshow('Translated Image', translate)

cv2.waitKey(0)

cv2.destroyAllWindows()
```

---

# Penjelasan Translation Matrix

```text
[1,0,x]
[0,1,y]
```

Keterangan:
- x → geser horizontal
- y → geser vertical

# Affine Transformation

Affine Transformation digunakan untuk:
- rotasi
- scaling
- translation
- shear

```python
import cv2
import numpy as np


image = cv2.imread('image.jpg')


rows, cols = image.shape[:2]


pts1 = np.float32([
    [50,50],
    [200,50],
    [50,200]
])


pts2 = np.float32([
    [10,100],
    [200,50],
    [100,250]
])


matrix = cv2.getAffineTransform(pts1, pts2)


affine = cv2.warpAffine(image, matrix, (cols,rows))


cv2.imshow('Affine Transform', affine)

cv2.waitKey(0)

cv2.destroyAllWindows()
```

---

# Penjelasan Affine

Affine transformation mempertahankan:
- garis lurus
- kesejajaran objek

Namun bentuk objek dapat berubah.

# Perspective Transformation

Perspective transformation digunakan untuk:
- memperbaiki sudut pandang
- bird eye view
- lane detection

```python
import cv2
import numpy as np


image = cv2.imread('image.jpg')


rows, cols = image.shape[:2]


pts1 = np.float32([
    [100,100],
    [400,100],
    [100,400],
    [400,400]
])


pts2 = np.float32([
    [0,0],
    [300,0],
    [0,300],
    [300,300]
])


matrix = cv2.getPerspectiveTransform(pts1, pts2)


perspective = cv2.warpPerspective(
    image,
    matrix,
    (300,300)
)


cv2.imshow('Perspective Transform', perspective)

cv2.waitKey(0)

cv2.destroyAllWindows()
```
