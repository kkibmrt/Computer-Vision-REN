# Color Space pada Computer Vision
## Memahami Format Warna Menggunakan OpenCV dan Python

---

# Apa Itu Color Space?

Color Space adalah representasi atau model warna yang digunakan komputer untuk menampilkan dan memproses gambar digital.

Pada Computer Vision, color space sangat penting karena:
- membantu deteksi objek
- mempermudah segmentasi warna
- meningkatkan akurasi AI
- membantu tracking objek

---

# Fungsi Color Space

Beberapa fungsi utama color space:

| Fungsi | Penjelasan |
|---|---|
| Representasi Warna | Menyimpan informasi warna |
| Object Detection | Membantu deteksi objek berdasarkan warna |
| Image Segmentation | Memisahkan objek berdasarkan warna |
| Tracking | Melacak objek tertentu |
| Filtering | Menyeleksi warna tertentu |

---

Output Hasil

# Color Space BGR pada OpenCV

Secara default, OpenCV menggunakan format:

```text
BGR
```

yang terdiri dari:
- Blue
- Green
- Red

---

# Struktur Warna BGR

| Channel | Fungsi |
|---|---|
| Blue | Intensitas warna biru |
| Green | Intensitas warna hijau |
| Red | Intensitas warna merah |

---

# Mengapa OpenCV Menggunakan BGR?

OpenCV menggunakan BGR karena alasan historis dan optimasi library sejak awal pengembangannya.

Walaupun kebanyakan sistem menggunakan RGB, OpenCV tetap menggunakan BGR sebagai format default.

---

# Konversi BGR ke RGB

Kadang gambar perlu diubah menjadi RGB agar sesuai dengan library lain seperti:
- matplotlib
- PIL
- deep learning framework

```python
import cv2


image = cv2.imread('image.jpg')


rgb = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)


cv2.imshow('RGB Image', rgb)

cv2.waitKey(0)

cv2.destroyAllWindows()
```

---

# Penjelasan `cvtColor()`

```python
cv2.cvtColor()
```

digunakan untuk mengubah format warna gambar.

Parameter:

| Parameter | Fungsi |
|---|---|
| image | Input gambar |
| COLOR_BGR2RGB | Konversi BGR ke RGB |

# HSV Color Space

HSV adalah color space yang sering digunakan pada Computer Vision.

HSV terdiri dari:
- Hue
- Saturation
- Value

---

# Struktur HSV

| Komponen | Fungsi |
|---|---|
| Hue | Jenis warna |
| Saturation | Intensitas warna |
| Value | Tingkat kecerahan |

---

# Keunggulan HSV

HSV lebih stabil untuk:
- deteksi warna realtime
- tracking objek
- segmentasi warna

Karena HSV tidak terlalu sensitif terhadap perubahan cahaya.

---

# Konversi BGR ke HSV

```python
import cv2


image = cv2.imread('image.jpg')


hsv = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)


cv2.imshow('HSV Image', hsv)

cv2.waitKey(0)

cv2.destroyAllWindows()
```

---

# Penjelasan HSV

```python
cv2.COLOR_BGR2HSV
```

digunakan untuk:
- konversi gambar ke HSV
- object tracking berbasis warna
- color filtering

---

# Deteksi Warna Menggunakan HSV

Contoh deteksi warna biru.

```python
import cv2
import numpy as np


image = cv2.imread('image.jpg')


hsv = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)


lower_blue = np.array([100,150,0])

upper_blue = np.array([140,255,255])


mask = cv2.inRange(hsv, lower_blue, upper_blue)


result = cv2.bitwise_and(image, image, mask=mask)


cv2.imshow('Original', image)

cv2.imshow('Mask', mask)

cv2.imshow('Result', result)

cv2.waitKey(0)

cv2.destroyAllWindows()
```

---

# Penjelasan Deteksi Warna

## `cv2.inRange()`

Digunakan untuk memilih warna tertentu.

```python
mask = cv2.inRange(hsv, lower_blue, upper_blue)
```

---

# Cara Kerja Masking

```text
Warna sesuai range HSV → putih
Warna di luar range → hitam
```

# LAB Color Space

LAB merupakan color space yang mendekati cara manusia melihat warna.

LAB terdiri dari:
- L → Lightness
- A → Green to Red
- B → Blue to Yellow

---

# Konversi ke LAB

```python
import cv2


image = cv2.imread('image.jpg')


lab = cv2.cvtColor(image, cv2.COLOR_BGR2LAB)


cv2.imshow('LAB Image', lab)

cv2.waitKey(0)

cv2.destroyAllWindows()
```

---

# Penggunaan LAB

LAB sering digunakan untuk:
- color correction
- image enhancement
- medical imaging
- industrial inspection

---

# YCrCb Color Space

YCrCb digunakan pada:
- video compression
- face detection
- digital television

Komponen:
- Y → luminance
- Cr → chroma red
- Cb → chroma blue

---

# Konversi ke YCrCb

```python
import cv2


image = cv2.imread('image.jpg')


ycrcb = cv2.cvtColor(image, cv2.COLOR_BGR2YCrCb)


cv2.imshow('YCrCb Image', ycrcb)

cv2.waitKey(0)

cv2.destroyAllWindows()
```
