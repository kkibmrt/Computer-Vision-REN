# Apa Itu Object Detection?

Object Detection adalah teknik Computer Vision yang digunakan untuk:
- mendeteksi keberadaan objek
- mengenali jenis objek
- mengetahui posisi objek pada gambar maupun video

Berbeda dengan image classification yang hanya mengenali isi gambar secara umum, object detection mampu:
- menemukan banyak objek sekaligus
- memberikan koordinat posisi objek
- menampilkan bounding box objek

---

# Face Detection pada Gambar

```python
import cv2


faceCascade = cv2.CascadeClassifier(
    'haarcascade_frontalface_default.xml'
)


image = cv2.imread('face.jpg')


gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)


faces = faceCascade.detectMultiScale(
    gray,
    scaleFactor=1.1,
    minNeighbors=5
)


for (x,y,w,h) in faces:

    cv2.rectangle(
        image,
        (x,y),
        (x+w,y+h),
        (0,255,0),
        2
    )


cv2.imshow('Face Detection', image)

cv2.waitKey(0)

cv2.destroyAllWindows()
```

---

# Face Detection Realtime

```python
import cv2


faceCascade = cv2.CascadeClassifier(
    'haarcascade_frontalface_default.xml'
)


camera = cv2.VideoCapture(0)


while True:

    success, frame = camera.read()

    if not success:
        break


    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)


    faces = faceCascade.detectMultiScale(
        gray,
        scaleFactor=1.1,
        minNeighbors=5
    )


    for (x,y,w,h) in faces:

        cv2.rectangle(
            frame,
            (x,y),
            (x+w,y+h),
            (0,255,0),
            2
        )


    cv2.imshow('Realtime Face Detection', frame)


    if cv2.waitKey(1) == ord('q'):
        break


camera.release()

cv2.destroyAllWindows()
```

---

# Penjelasan Program Realtime

Program:
- membuka kamera
- membaca frame realtime
- mendeteksi wajah
- menampilkan bounding box
- menampilkan hasil realtime

# Eye Detection

OpenCV juga dapat mendeteksi mata.

```python
import cv2


eyeCascade = cv2.CascadeClassifier(
    'haarcascade_eye.xml'
)


image = cv2.imread('face.jpg')


gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)


eyes = eyeCascade.detectMultiScale(gray)


for (x,y,w,h) in eyes:

    cv2.rectangle(
        image,
        (x,y),
        (x+w,y+h),
        (255,0,0),
        2
    )


cv2.imshow('Eye Detection', image)

cv2.waitKey(0)

cv2.destroyAllWindows()
```
