# 📌 Apa Itu Computer Vision?

Computer Vision adalah salah satu cabang dari Artificial Intelligence (AI) yang memungkinkan komputer untuk "melihat", memahami, dan menganalisis gambar maupun video layaknya penglihatan manusia.

Tujuan utama dari Computer Vision adalah membuat sistem komputer mampu:

- Mengenali objek
- Membaca gambar
- Memahami lingkungan sekitar
- Mendeteksi pergerakan
- Mengambil keputusan berdasarkan visual

Computer Vision banyak digunakan pada berbagai bidang teknologi modern seperti:

| Bidang | Contoh Penggunaan |
|---|---|
| Robotics | Robot navigasi otomatis |
| Autonomous Vehicle | Kapal tanpa awak |
| Security System | Face recognition dan CCTV AI |
| Medical Imaging | Deteksi penyakit dari X-Ray |
| Industrial Automation | Quality control produk |
| Smart City | Traffic monitoring |

---

# 🧠 Cara Kerja Computer Vision

Secara umum, alur kerja Computer Vision adalah:

```text
Kamera / Gambar
        ↓
Akuisisi Data Visual
        ↓
Image Processing
        ↓
Analisis dan Deteksi
        ↓
Pengambilan Keputusan
```

Pada sistem realtime, kamera akan terus mengambil frame video secara terus-menerus untuk diproses oleh komputer.

# 📷 OpenCV pada Computer Vision

OpenCV menyediakan berbagai fitur seperti:

- Membaca gambar
- Mengakses kamera
- Pengolahan citra
- Deteksi objek
- Tracking
- Face detection
- Machine Learning
- Deep Learning integration

OpenCV mendukung berbagai bahasa pemrograman seperti:
- Python
- C++
- Java

Pada dokumentasi ini, OpenCV digunakan menggunakan bahasa Python.

# 📷 Inisialisasi Kamera

Pada Computer Vision realtime, langkah pertama adalah membuka akses kamera.

```python
camera = cv2.VideoCapture(0)
```

## Penjelasan

Fungsi `VideoCapture()` digunakan untuk menghubungkan program dengan kamera.

| Parameter | Fungsi |
|---|---|
| 0 | Kamera utama/default |
| 1 | Kamera eksternal |
| 2 | Kamera tambahan |

Jika komputer memiliki lebih dari satu kamera, indeks dapat berubah.

---

# 🔍 Mengecek Status Kamera

```python
if (camera.isOpened()):
    print("The camera is successfully opened")

else:
    print("Could not open the camera")
```

## Penjelasan

Fungsi:

```python
camera.isOpened()
```

digunakan untuk memeriksa apakah kamera berhasil dibuka atau tidak.

Jika:
- `True` → kamera aktif
- `False` → kamera gagal diakses

Kegagalan biasanya terjadi karena:
- kamera dipakai aplikasi lain
- driver kamera bermasalah
- kamera tidak terhubung
- permission sistem belum diberikan

---

# 📐 Membaca Properti Kamera

Setelah kamera berhasil dibuka, kita dapat membaca berbagai properti kamera.

```python
frameWidth = int(camera.get(cv2.CAP_PROP_FRAME_WIDTH))

frameHeight = int(camera.get(cv2.CAP_PROP_FRAME_HEIGHT))

frameRate = int(camera.get(cv2.CAP_PROP_FPS))
```

---

# 📊 Penjelasan Camera Properties

| Property | Fungsi |
|---|---|
| CAP_PROP_FRAME_WIDTH | Lebar frame video |
| CAP_PROP_FRAME_HEIGHT | Tinggi frame video |
| CAP_PROP_FPS | Frame per second kamera |

---

# 🧠 Apa Itu Frame?

Frame adalah satu gambar tunggal pada video.

Video sebenarnya merupakan kumpulan banyak frame yang ditampilkan secara cepat.

Contoh:
- 30 FPS = 30 frame per detik
- 60 FPS = 60 frame per detik

Semakin tinggi FPS:
- video semakin halus
- respon sistem lebih cepat

---

# 🎥 Menampilkan Video Realtime

Berikut program realtime video sederhana menggunakan OpenCV.

```python
import cv2


camera = cv2.VideoCapture(0)



if (camera.isOpened()):
    print("The camera is successfully opened!")
else:
    print("Could not open the camera")

while True:

    success, frame = camera.read()

    if not success:
        print("Not able to read the frame. End.")
        break

    cv2.imshow('Camera video', frame)


    if cv2.waitKey(1) == ord('r'):
        break


camera.release()
cv2.destroyAllWindows()
```

---

# 🔄 Alur Program Realtime Camera

```text
Inisialisasi Kamera
        ↓
Baca Frame Kamera
        ↓
Tampilkan Frame
        ↓
Tunggu Input Keyboard
        ↓
Ulangi Proses
```

---

# 📥 Membaca Frame Kamera

```python
success, frame = camera.read()
```

## Penjelasan

Fungsi:

```python
camera.read()
```

digunakan untuk mengambil frame terbaru dari kamera.

Output terdiri dari:

| Variabel | Fungsi |
|---|---|
| success | Status pembacaan frame |
| frame | Gambar/frame yang berhasil dibaca |

Jika:
- `success = True` → frame berhasil dibaca
- `success = False` → frame gagal dibaca

---

# 🖼 Menampilkan Frame

```python
cv2.imshow('Camera video', frame)
```

## Penjelasan

Fungsi `imshow()` digunakan untuk menampilkan gambar atau video pada window OpenCV.

| Parameter | Fungsi |
|---|---|
| 'Camera video' | Nama window |
| frame | Gambar yang ditampilkan |

# ⌨️ Keyboard Control

Fungsi:


# 🧹 Menutup Kamera dan Window

```python
camera.release()
cv2.destroyAllWindows()
```

## Penjelasan

### `camera.release()`
Digunakan untuk:
- melepaskan akses kamera
- menghentikan penggunaan webcam

### `cv2.destroyAllWindows()`
Digunakan untuk:
- menutup seluruh window OpenCV

Langkah ini sangat penting untuk mencegah:
- memory leak
- kamera terkunci
- crash aplikasi
