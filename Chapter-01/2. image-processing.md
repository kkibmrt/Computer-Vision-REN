# 📌 Apa Itu Image Processing?

Image Processing adalah proses manipulasi dan analisis gambar menggunakan algoritma komputer untuk memperoleh informasi tertentu atau meningkatkan kualitas visual gambar.

Pada Computer Vision, image processing merupakan tahap awal sebelum sistem AI melakukan:
- deteksi objek
- klasifikasi gambar
- tracking
- pengenalan wajah
- analisis visual lainnya

Image processing membantu komputer memahami gambar seperti cara manusia melihat lingkungan sekitar.

---

# Tujuan Image Processing

Beberapa tujuan utama image processing:

| Fungsi | Penjelasan |
|---|---|
| Noise Reduction | Mengurangi gangguan pada gambar |
| Edge Detection | Mendeteksi tepi objek |
| Color Conversion | Mengubah format warna |
| Thresholding | Memisahkan objek dari background |
| Image Enhancement | Memperjelas kualitas gambar |
| Object Segmentation | Memisahkan objek tertentu |

# 📷 Membaca Gambar Menggunakan OpenCV

Program pertama pada image processing adalah membaca gambar.

```python
import cv2


image = cv2.imread('image.jpg')


cv2.imshow('Original Image', image)

cv2.waitKey(0)

cv2.destroyAllWindows()
```

---

# 📌 Penjelasan Program

## `cv2.imread()`

Digunakan untuk membaca gambar dari file.

```python
image = cv2.imread('image.jpg')
```

Parameter:
- `'image.jpg'` → nama file gambar

Jika gambar gagal dibaca:
- path file salah
- file tidak ada
- format tidak didukung

---

## `cv2.imshow()`

Digunakan untuk menampilkan gambar.

```python
cv2.imshow('Original Image', image)
```

| Parameter | Fungsi |
|---|---|
| 'Original Image' | Nama window |
| image | Gambar yang ditampilkan |

---

## `cv2.waitKey(0)`

Digunakan untuk menunggu input keyboard.

```python
cv2.waitKey(0)
```

Nilai:
- `0` → menunggu tanpa batas
- `1` → delay 1 ms

---

## `cv2.destroyAllWindows()`

Digunakan untuk menutup seluruh window OpenCV.

```python
cv2.destroyAllWindows()
```

```text

```

Bukan:

```text
RGB
```

# 📊 Perbedaan RGB dan BGR

| Format | Urutan |
|---|---|

# 🎨 Konversi ke Grayscale

Grayscale digunakan untuk mengurangi kompleksitas data gambar.

```python
import cv2


image = cv2.imread('image.jpg')


gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)


cv2.imshow('Gray Image', gray)

cv2.waitKey(0)

cv2.destroyAllWindows()
```

---

# 📌 Penjelasan Grayscale

Grayscale adalah gambar hitam putih yang hanya memiliki intensitas cahaya.

Keuntungan grayscale:
- processing lebih cepat
- data lebih ringan
- cocok untuk AI preprocessing
- mempermudah edge detection

---

# ⚡ Thresholding

Thresholding digunakan untuk mengubah gambar menjadi hitam putih.

```python
import cv2


image = cv2.imread('image.jpg')


gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)


_, threshold = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)


cv2.imshow('Threshold Image', threshold)

cv2.waitKey(0)

cv2.destroyAllWindows()
```

---

# 📌 Penjelasan Threshold

```python
cv2.threshold()
```

digunakan untuk memisahkan objek dari background.

Parameter:

| Parameter | Fungsi |
|---|---|
| gray | Input grayscale |
| 127 | Nilai threshold |
| 255 | Nilai maksimum pixel |
| THRESH_BINARY | Mode threshold |

---

# 📊 Cara Kerja Threshold

```text
Pixel < 127  → Hitam
Pixel > 127  → Putih
```

---

# 🔍 Edge Detection Menggunakan Canny

Edge Detection digunakan untuk mendeteksi garis tepi objek.

```python
import cv2


image = cv2.imread('image.jpg')


gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)


edges = cv2.Canny(gray, 100, 200)


cv2.imshow('Edge Detection', edges)

cv2.waitKey(0)

cv2.destroyAllWindows()
```

---

# 📌 Penjelasan Canny Edge Detection

Fungsi:

```python
cv2.Canny()
```

digunakan untuk:
- mendeteksi tepi objek
- mengenali bentuk objek
- preprocessing AI vision

Parameter:

| Parameter | Fungsi |
|---|---|
| gray | Input grayscale |
| 100 | Threshold bawah |
| 200 | Threshold atas |

---

# 📷 Gaussian Blur

Blur digunakan untuk mengurangi noise pada gambar.

```python
import cv2


image = cv2.imread('image.jpg')


blur = cv2.GaussianBlur(image, (5,5), 0)


cv2.imshow('Blur Image', blur)

cv2.waitKey(0)

cv2.destroyAllWindows()
```

---

# 📌 Penjelasan Gaussian Blur

Gaussian Blur digunakan untuk:
- menghaluskan gambar
- mengurangi noise
- membantu proses deteksi objek

---

# 📊 Parameter Gaussian Blur

| Parameter | Fungsi |
|---|---|
| (5,5) | Ukuran kernel |
| 0 | Sigma default |

# ✂ Crop Gambar

Crop digunakan untuk mengambil bagian tertentu dari gambar.

```python

image = cv2.imread('image.jpg')


crop = image[100:400, 200:500]


cv2.imshow('Crop Image', crop)

cv2.waitKey(0)

cv2.destroyAllWindows()
```

---

# 📌 Penjelasan Crop

Format crop:

```python
image[y1:y2, x1:x2]
```
